# Pritam Gurung — Personal Portfolio

Source code for my personal portfolio website.

The site was built as a simple static portfolio using HTML and CSS to present my background, projects, and professional information in one place.

## Tech Stack

- HTML5
- CSS3
- GitHub Pages / static hosting workflow

## Repository Structure

- `index.html` — main portfolio page
- `styles.css` — site styling
- `assets/` — supporting images and media
- `cv/` — CV-related assets
- `.github/` — repository workflow/configuration files

## Status

This repository represents an earlier version of my personal portfolio. My current professional information is maintained primarily through my CV, LinkedIn, and GitHub project repositories.
